-----Seccion de codificacion Hamming:-----
def codificar_hamming_74(bloque_4bits):
    d1, d2, d3, d4 = bloque_4bits
    p1 = d1 ^ d2 ^ d4
    p2 = d1 ^ d3 ^ d4
    p3 = d2 ^ d3 ^ d4
    return [p1, p2, d1, p3, d2, d3, d4]
Explicacion: Aquí el script toma el texto, lo pasa a binario y lo divide en bloques de 4 bits, agregándoles otros
3 bits de paridad para lograr detectar y corregir errores automáticamente.

-----Seccion de Calculo de BER-----
def calcular_ber(bits_enviados, bits_recibidos):
    errores = sum(e != r for e, r in zip(bits_enviados, bits_recibidos))
    return errores / len(bits_enviados)
